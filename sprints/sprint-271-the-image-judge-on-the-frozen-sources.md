## scope

The Decision "Sequence for step 6" put the memory XCHG first (census D1). Its card's lookup found the C compiler inside
the VM compiles a memory XCHG too: `store/stencil/table.txt.gz` holds 25 memory XCHG forms with stencils (32- and
64-bit, base, base and index, RIP-relative), lowered as the frozen host lowered them, a load and a plain store. So the
fix reaches the C runtime, as plan step 6 says its lock changes do ("in the C runtime, changed only there", 162). Any
change there fails `crates/guest_runtime/tests/python_image.rs`, which builds the working tree's C and requires the
frozen Python build's image under the same key. This card moves that judge to the C sources as they stood at the tag
`frozen-python-2026-10-29`, so it still proves the Rust build reproduces the Python build byte for byte while the
working tree's C may change; the XCHG becomes card 272.

- **Where it stands, by lookup (2026-10-30):**
  - `guest_runtime::build(root, …)` reads everything under the root it is given: the C texts (`texts`,
    `tools/guest_runtime/*.c`), `runtime.h`, the four generated headers from `specs/` (`generated_headers`), and keys
    the image by them (`cache_key`); the test passes the repository's root.
  - `git diff --quiet frozen-python-2026-10-29 -- tools/guest_runtime tools/vm_compiler` exits 0: the C is the tag's.
  - `stencil_table.h` is "GENERATED by scripts/gen_stencil_table.py", 701 lines of Python at the tag, which no longer
    runs (the Decision "No Python runs"); a C change that declines a form needs no new table.
- **The work:**
  - `python_image.rs` exports the tag's `tools/` and `specs/` with `git archive` into a temporary root, builds there,
    and holds the image byte for byte to `build/guest_runtime/<key>.bin`, as today.
  - A second test: the working tree's image builds, and its key equals the frozen one while the C is unchanged, so a
    later card that changes the C sees the key move and names it.
  - The Decision "Sequence for step 6" annotated: 272 the XCHG, the cards after it one later.
- **Not here:** the XCHG's change (card 272).
