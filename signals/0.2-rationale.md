# signals/0.2 — rationale

Additive successor to `signals/0.1.json`, locked 2026-10-07. `0.1.json` and `0.1-rationale.md` stay on disk unchanged as the audit trail. `signals/current.json` names the version in force.

## What changed

| Proposal | Kind | Change | Why |
|---|---|---|---|
| P8 | INVARIANT_PROPOSED (Layer 7) | `types.version` reads major.minor[.patch]; `types.u64` / `types.i64` state the harness-plane bound ±(2^53−1) | Sprint 002 found `substrate.api.canonical_bytes(2**53)` raises NonCanonicalValueError (RFC 8785 numbers are IEEE-754 doubles), and the vocabulary's own version "0.1" contradicted its `types.version` text. The generator enforced both already; the contract now says so. |
| P9 | PAYLOAD_FIELD_PROPOSED (Layer 2) | `MEASUREMENT_RECORDED.metric` gains `ns_per_access`; optional field `variant` (text) | v0.2 §8.2 and §13 require per-access cost of ordering enforcement on both backends. No metric expressed it and no field named the lowering or configuration measured. |

Layer 10 also gains a rule: each version lists the earlier versions whose guest traces it still ingests (`guest_plane_compatible_versions`). 0.2 lists 0.1 and 0.2, because no guest tag changed. A change to any guest tag would drop earlier versions from the list, and the ingester would refuse those traces rather than misread them.

## What did not change

All 60 tags and their required payloads, every enum's existing values in order, all invariants, transitions, operators, and evidence constraints. This was checked mechanically on 2026-10-07: 0.1 tag names ⊆ 0.2, required payloads equal, optional payloads ⊆, guest tags identical, enum prefixes equal.

## Compatibility evidence

The 11 reference traces committed under `store/traces/` (vocab 0.1) still ingest under 0.2 (`tests/test_trace.py::test_every_committed_reference_trace_still_ingests`). TRACE_INGESTED now records the trace's own vocabulary version, not the harness's, so a record says which contract the trace was written against.
