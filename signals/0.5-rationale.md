# signals/0.5 — rationale

Successor to `signals/0.4.json`, locked 2026-10-08. 0.1-0.4 stay on disk unchanged.

## What changed

| Proposal | Kind | Change | Why |
|---|---|---|---|
| P14 | TAG_PROPOSED | guest tag `GUEST_THREAD_STATE_OBSERVED` (subject_thread_id, thread_state, wait_reason, source) | A contract precondition about another thread's state ("both waiters are pending") had no way into a trace; the event probe assumed it after `Sleep(200)` (project review 2026-10-08, §4.7). |

The values are the operating system's raw numbers, not a w2m enum: the comparator interprets them through the contract, which cites the documentation for each value it relies on (Wait = 5, UserRequest = 6 on Windows).

## Compatibility

Existing guest tags are unchanged, so 0.5 ingests traces written under 0.1-0.5. A trace that uses the new tag declares `vocab_version` 0.5 and does not ingest under 0.4. The harness plane is unchanged.
